# シフト表作成ツール

入りたい時間・入れない時間をファイルで集めて、シフト表を組むためのツールです。サーバーは不要で、ブラウザだけで動きます。

## 使い方

担当者の流れ:

1. **表を作る** — 日付(横)と時間帯(縦)の表を、見出しを直接書き換えて作ります。セルの数字はその枠に必要な人数で、ドラッグで選んでまとめて変えられます。「日付の範囲から列を作る」「時間の範囲から行を作る」で一気に作ることもできます。完成したら「枠ファイルを書き出す」。
2. **希望を集める** — 枠ファイル(`shift-frame.json`)をスタッフに配ります。スタッフは同じ画面の「スタッフ用:希望を出す」で希望ファイルを作って返します(`index.html?mode=submit` を開くとその画面だけが出ます)。返ってきたファイルを「希望ファイルを読み込む」でまとめて読み込みます。
3. **振り分ける** — 「自動で振り分ける」で案を作り、「別の案を出す」で組み直せます。セルをクリックすると手で直せます。CSV出力と印刷ができます。

スタッフの流れ: 枠ファイルを開く → 名前を入れる → ペン(○入りたい / ×入れない)でセルを塗る → 希望ファイルを書き出して担当者に送る。何も塗らない時間は「入れる」になります。

データはブラウザ内(localStorage)に保存されます。「全データをJSON保存」で書き出せます。

## 振り分けのロジック(現在)

実装は `scheduler.js` の `autoAssign` です。

**守ること(絶対)**
- 「入れない」時間には入れない
- 週の上限(月曜始まりの1週間に入れる枠の数)を超えない
- 同じ枠に同じ人を2回入れない

**考えること(順番に)**
1. 枠の処理順: 「入れない」でない人(候補)が少ない枠から先に埋める。同数なら乱数で決める
2. 各枠で人を選ぶ順: 「入りたい」の人を先に、次にそこまでの回数が少ない人、同順位なら乱数
3. 必要人数に届かないときは、足りない人数を「不足」として警告に出す

これは貪欲法(その場で良い選択を重ねる方法)です。最適解は保証しません。同じ seed(「案1」「案2」の番号)なら同じ結果になります。「別の案を出す」は seed を変えて組み直します。案ごとに次の評価を表示します。

- 入りたい希望: 「入りたい」と書いた枠のうち、実際に入れた割合
- 人数不足: 足りない人数の合計
- 回数の差: 最も多い人と最も少ない人の回数の差

## ありうる振り分けの数

数えているのは「必要人数ちょうどを満たし、『入れない』と週の上限を守る振り分け」の数です。

- 週の上限がない場合: 各枠で「入れない」でない人から必要人数を選ぶ組み合わせ C(候補数, 必要数) の積で、厳密に求まります
- 週の上限がある場合: 組み合わせが約1000万以下なら、すべて数え上げて**厳密**に求めます。それより大きいときは**概算**にします
- 概算の方法: 枠を順に決め、その時点で週の上限を守れる人だけから無作為に選びます。そのとき選べた組み合わせ数の積を3000回平均します(Knuth の推定法)。誤差があります
- 「数え方」で、自動・厳密・概算を選べます。厳密は大きな表では時間がかかり、途中で打ち切って概算に切り替えます

## 今後の改善案

振り分けの方法を数理的に見直す余地があります。ツールを作り込む段階で、次を比較して選ぶ予定です。

- 最小費用流・割当問題として解く(上限のない場合に最適解が得られる)
- 整数計画法(ILP)で、希望の充足と公平さを同時に最適化する
- 貪欲法の結果を、入れ替えで少しずつ良くする局所探索
